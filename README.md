# PitPédia

Projeto de site estático sobre Fórmula 1, desenvolvido com HTML e CSS.

## O que já está incluído

- Página inicial com navegação para as seções do site.
- Lista de equipes, com links para páginas individuais.
- Página da Ferrari com informações sobre seus pilotos e chefe de equipe.
- Estilos compartilhados para a navegação, os cartões das equipes e os detalhes da Ferrari.

O projeto ainda está em desenvolvimento: as páginas de pilotos e calendário estão vazias, e algumas páginas individuais de equipes ainda precisam ser criadas.

## Como abrir

Abra o arquivo `index.html` em um navegador. Não é necessário instalar dependências ou executar um processo de build.

As imagens das equipes são carregadas de sites externos e precisam de conexão com a internet.

## Arquivos principais

- `index.html` — página inicial.
- `equipes.html` — lista de equipes.
- `ferrari.html` — detalhes da Ferrari.
- `pilotos.html` — seção de pilotos, ainda em desenvolvimento.
- `calendario.html` — seção de calendário, ainda em desenvolvimento.
- `style.css` — estilos compartilhados.
